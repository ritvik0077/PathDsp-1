# PathDSP frontend

React + Vite landing page using Tailwind CSS v4 and Motion for React.

## Run locally

1. Install Node.js 20.19+ or 22.12+.
2. In this folder, run: pnpm install (or npm install).
3. Start the app with: pnpm dev (or npm run dev). Open the local URL Vite prints.

For a production build, run pnpm build (or npm run build). Preview that build with pnpm preview.

## Files

- index.html is the Vite entry point.
- src/App.jsx contains the PathDSP landing page and demo interaction.
- src/index.css imports Tailwind and defines the color theme.
- vite.config.js configures the React and Tailwind Vite plugins.

## Notes

The prediction lab is a local synthetic demonstration. No trained model, dataset, or API is connected. Its SHAP bars are fabricated interface examples and do not represent scientific results or causal effects.
